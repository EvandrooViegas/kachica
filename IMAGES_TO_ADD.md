## How to Download from Unsplash

1. Click any link above
2. Right-click the image and select "Save image as..."
3. Name it according to the filename listed above
4. Save to the corresponding folder in `/public/`

## Alternative: Using Unsplash Search

Visit https://unsplash.com and search for:
- E-commerce / Shopping
- Analytics / Dashboard
- AI / Automation / Technology

Download free images and place them in the appropriate folders with the names listed above.

All images should be:
- JPG format
- Approximately 600x400px (or similar ratio)
- Optimized for web (compressed)
